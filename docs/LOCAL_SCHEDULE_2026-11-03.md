## Согласованные исключения исходной таблицы

Готовые пары имеют приоритет только на 3 ноября. Общие настройки других дат не изменялись. Для Потаповой Р. А. разрешены только исходные пары 3–5; для Садриевой Т. Г. — пары 2–3. Сохранены три исходные общие пары ИИ у ТОРД-3706, три ЛПЗ у СП-Пф-3602п и исходный день с пятью парами первой подгруппы ТОРД-3707п. Для расчёта использованы отдельные входные данные с этими исключениями; это не изменение общих семестровых квот.

В Конструкторе вторая УП МЦМ-408 остаётся в исходной строке 2 с интервалом 12:30–16:00. В основном расписании используется позиция уже подтверждённого события журнала — модельная строка 3; исходная строка и время сохранены в метаданных события. Это одно занятие, а не дополнительная практика. Проверка ресурсов учитывает фактический интервал, а не номер строки Excel.

## Проверка

- `output/latest/strict_audit.json` — проверка расчётного входа генератором.
- `output/latest/generation_input_with_source_exceptions.json` — вход выбранного дня с согласованными исключениями; исторический снимок до последующих отметок проведённых занятий.
- `output/latest/independent_validation_input.json` и `independent_strict_audit.json` — дополнительная проверка выбранных генератором квот. Датированные исключения развёрнуты на один день; проверка окон преподавателей выполнена отдельно по полным интервалам УП.
- `output/latest/constructor_verification.json` — сохранность закреплений, остальные даты и проверка временных интервалов кабинетов, преподавателей и подгрупп.
- `output/latest/constructor_transfer_verification.json` — соответствие основного расписания проверенному расчёту, сохранность Конструктора и учёта, проверка API всех групп и прокси фронтенда.

Пересечений по фактическому времени, окон и неназначенных учебных кабинетов не обнаружено. Предупреждения о семестровой обеспеченности в отчёте сохранены. Перед новой генерацией с иным диапазоном требуется отдельная проверка его исходных ограничений.
