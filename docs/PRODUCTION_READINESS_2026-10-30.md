- Результат диапазона отображает выбранные даты, включая после перезагрузки
  страницы; исторические недели остаются доступны.
- Границы сохраняются в JSON результата и используются при экспорте Excel.
- Неполные и ошибочные параметры API отклоняются без запуска полного периода.
- Действующий предел диапазона — 7 календарных дней; интерфейс сообщает об этом.
- Linux-сборка явно подключает Threads; разрыв HTTP-соединения не завершает
  Linux-бэк через SIGPIPE.
- Docker собирает и проверяет C++/GCC, фронт и зависимости. В одном контейнере
  запускаются Node и C++: фронт, API и Excel-экспорты доступны через порт 8080.
- Node обнаруживает Linux-бинарник и завершает процесс при аварии дочернего
  бэка, чтобы Docker мог перезапустить приложение.
- Обновлены совместимые зависимости; production npm audit показывает 0
  уязвимостей. Инструменты разработки удаляются из исполняемого образа.

## До публичного переключения

Использовать [инструкцию обновления](../deploy/README.md) и
[образец nginx](../deploy/nginx.conf.example). Действующий nginx раздаёт старый
фронт отдельно: при переключении все пути нужно направить в новый Node-сервер.
На сервере сейчас настроен HTTP; домен/HTTPS либо закрытый доступ через VPN
нужно согласовать перед публичным запуском.

Изменения в рабочем Git-каталоге сохранены; push и обновление боевого checkout
не выполнялись. Ветка локального проекта — `uchet`, базовый коммит `17a048d`.

Новая генерация по полной реальной базе не выполнялась. Успешные тесты
генерации подтверждают перечисленные сценарии; конкретное рабочее расписание
нужно отдельно проверить строгим аудитом, кабинетами, нагрузкой и закреплениями
перед публикацией. Генерация сама по себе расписание не публикует.
