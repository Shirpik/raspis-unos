# Дизайн-система проекта

## Цветовая палитра

### Основные цвета
- **Фон**: `#0B0E14` (очень темный серый, почти черный)
- **Фон вторичный**: `#1C2028` (темно-серый)
- **Фон третичный**: `#252932` (средне-темный серый)
- **Текст**: `#F8FAFC` (почти белый)
- **Акцент**: `#FB923C` (оранжевый Cloudflare-стиль)

### Состояния
- Success: `#22C55E` (зеленый)
- Error: `#EF4444` (красный)
- Warning: `#EAB308` (желтый)

## Типографика

### Шрифты
- **Основной**: Inter (sans-serif)
- **Альтернативный**: Onest (sans-serif)
- Моноширинный для кода/данных: system monospace

### Размеры
- Заголовок страницы: 24px/700
- Заголовок карточки: 16px/600
- Основной текст: 14px/400-500
- Мелкий текст: 12-13px/500

## Компоненты

### Кнопки
- Основная (Primary): оранжевый акцент, черный текст
- Вторичная (Secondary): темно-серый фон
- Ghost: прозрачная с обводкой
- Размеры: sm (6px), default (10px), lg (12px)

### Карточки
- Фон: `var(--bg-card)` с backdrop-filter
- Граница: 1px solid `var(--border)`
- Радиус: 10px
- Тень при наведении

### Формы
- Input/Select: темно-серый фон, тонкая обводка
- Focus: оранжевый акцент + shadow
- Placeholder: приглушенный текст

### Модальные окна
- Backdrop: rgba(0,0,0,0.75) + blur(8px)
- Анимация: scale + translateY
- Mobile: slide from bottom

## Анимации

### Переходы
- По умолчанию: 0.2s ease
- Hover эффекты: translateY(-1px)
- Active состояния: scale(0.98)

### Ключевые анимации
- `pulse`: для индикаторов загрузки
- `spin`: для спиннеров
- `slide-in`: для появления элементов
- `skeleton-loading`: для skeleton screens

## Иконки
- Библиотека: lucide-vue-next
- Размеры: 18px (default), 20px (mobile menu), 48px (empty states)

## Адаптивность
- Desktop: max-width 1400px
- Tablet: < 900px (мобильное меню)
- Mobile: < 640px (компактные отступы)

## Принципы
1. Минимализм без упрощения
2. Четкая иерархия через типографику и цвет
3. Тонкие, ненавязчивые анимации
4. Строгий, профессиональный вид
5. Mobile-first подход
6. Высокая контрастность для читаемости
