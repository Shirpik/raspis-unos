# Дедлайн-трекер

Многофункциональное русскоязычное приложение для учёта дедлайнов с тёмным интерфейсом.

## Запуск

```bash
pip install -r requirements.txt
python deadline_tracker.py
```

Дедлайны автоматически сохраняются в файл `deadlines.json` рядом с программой.

Также можно открыть готовую Windows-версию: `dist/DeadlineTracker.exe`. Установка Python для неё не нужна.

## Возможности

- создание, редактирование и удаление задач;
- приоритеты и индикаторы состояния;
- обратный отсчёт до дедлайна;
- фильтры и статистика;
- отметка о выполнении.
- поиск, категории, заметки и сортировка;
- панель ближайших задач и сводная статистика;
- дублирование задач, очистка выполненных;
- импорт и экспорт резервных копий JSON;
- светлая/тёмная тема и горячие клавиши `Ctrl+N`, `Ctrl+F`.
