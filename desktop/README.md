# Расписание УСПО — desktop

Локальная оболочка запускает C++/OR-Tools-решатель и Vue-интерфейс без внешнего сервера. API и интерфейс слушают только `127.0.0.1` на свободных портах. Версия 1.3.1 содержит утверждённую пятницу и исправленную субботу, применяет правила кабинетов по маркеру `ЛПЗ`, проверяет полный набор жёстких ограничений и только после этого заменяет рабочий вариант. Excel-экспорт формируется по утверждённому четырёхлистовому образцу.

## Данные

При первом запуске исходная папка `data` и актуальные результаты копируются в:

```text
%APPDATA%\raspis-uspo-desktop\workspace
```

Обычные обновления приложения не перезаписывают рабочую базу. Обновление с 1.3.0 до 1.3.1 один раз устанавливает исправленную субботу и предварительно сохраняет полную резервную копию в `update-backups`. В меню **Файл** можно открыть папки данных/результатов и создать резервную копию.

## Сборка

Сначала должен быть собран `frontend/dist`, а в `build-desktop` должны находиться `timetable_solver.exe` и его DLL. Три DLL Microsoft Visual C++ Runtime уже лежат в `desktop/runtime` и автоматически включаются в установщик.

```powershell
cd frontend
npm run build
cd ..\desktop
npm install
npm run smoke
npm run dist
```

Готовый установщик появится в `desktop/release`.
