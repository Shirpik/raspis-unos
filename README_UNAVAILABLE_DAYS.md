# Недоступность групп и особые дни

Данные лежат в `data/timetable_data.json`, секция `unavailable`.
После изменения данных нужно вызвать:

```http
POST /api/schedule/regenerate
```

## 1. Несколько конкретных дат для одной группы

```json
{
  "group": 0,
  "dates": ["2026-02-23", "2026-03-09"],
  "text": "Праздничный день"
}
```

Что будет:
- в эти даты группе запрещаются обычные занятия;
- в расписании группы будет выведен день;
- только в первой паре будет текст `Праздничный день`;
- остальные пары будут `-`.

## 2. Несколько дат для всех групп

```json
{
  "all_groups": true,
  "dates": ["2026-02-23", "2026-03-09"],
  "text": "Праздничный день"
}
```

## 3. Старый формат диапазона всё ещё работает

```json
{
  "group": 0,
  "from": "2026-04-30",
  "to": "2026-06-19",
  "text": "Производственная практика"
}
```

Если `text` указан, он будет отображаться в первой паре каждого учебного дня диапазона.
Если `text` не указан, дни просто блокируются и не выводятся как отдельные строки.

## API

Получить все недоступности:

```http
GET /api/unavailable
```

Добавить:

```http
POST /api/unavailable
Content-Type: application/json

{
  "all_groups": true,
  "dates": ["2026-05-01", "2026-05-09"],
  "text": "Праздник"
}
```

Изменить частично:

```http
PATCH /api/unavailable/0
Content-Type: application/json

{
  "text": "ПП"
}
```

Удалить:

```http
DELETE /api/unavailable/0
```
